# Где жить

Приложение для Михаила и Вики: карта мест, где были и куда смотрим, раздельные оценки по 69 подкатегориям, рейтинг с весами, мировые показатели на карте и «похожие места». Сайт: https://mihinator3000.github.io/where-to-live/

Код и открытые мировые данные — здесь, в публичном репозитории. Наши места и оценки — в приватном `Mihinator3000/where-to-live-data`: сайт читает и пишет туда прямо из браузера по токену, сервера нет.

## Как начать на телефоне

1. Открыть сайт в Safari → «Поделиться» → «На экран „Домой“». Дальше открывать с иконки: так данные не стираются через 7 дней, как во вкладке Safari.
2. В приложении: ⚙ → «Кто я» → Михаил или Вика.
3. ⚙ → «Доступ к данным» → «Как получить токен» → создать токен (ссылка уже подставляет имя, срок и права) → вставить → «Сохранить и проверить». Предложит сохранить в Связке ключей — согласиться.

## Токены

- Fine-grained, только репозиторий `where-to-live-data`, право Contents: Read and write, без срока.
- Создаёт Михаил: GitHub не даёт fine-grained токену collaborator-а писать в чужой личный репозиторий, поэтому у Вики свой отдельный токен из аккаунта Михаила с именем `where-to-live-vika-…`.
- Один токен на одно устройство: потерял телефон — отозвал только его (github.com → Settings → Developer settings → Fine-grained tokens).
- Токен хранится на устройстве и уходит только на api.github.com. В репозитории и в коде его нет.
- Хранилище браузера общее для всех Pages-сайтов аккаунта (`mihinator3000.github.io`), сейчас там ещё ReportGenerator и Web. Их скрипты теоретически могут прочитать токен во вкладке Safari. Приложение с иконки на экране «Домой» хранит данные отдельно от Safari, поэтому открывайте его с иконки. Убрать риск совсем можно двумя способами: выключить Pages у старых сайтов или перенести приложение на свой домен.

## Что внутри

- `index.html`, `css/`, `js/` — без сборки, ES-модули. Leaflet и шрифты лежат в `vendor/`.
- `js/calc.js` — логика методики, перенесена из `~/Notes/scripts/where-to-live/dashboard.html`: оценка человека по поездкам с весами сезона и режима, минимум М/В в рисковых группах, доли «мы / живущие+данные» по видимости, итог с весами, разброс места, флаги.
- `schema.json` — группы и подкатегории. Источник — `wtl.py` в vault; после правки категорий: `python3 scripts/export_schema.py`.
- `js/store.js` — GitHub: чтение одним GraphQL-запросом, запись одним коммитом (`createCommitOnBranch`, запасной путь — REST Git Data), проверка головы ветки с ETag раз в минуту. Без сети правки копятся в очереди и уходят при появлении связи.
- `js/world.js`, `js/similar.js` — мировые показатели в шкале 1–5 (Россия/СПб = 3) и «похожие места» (взвешенный Gower по нашим весам + климат по месяцам).
- `data/world/` — открытые данные: показатели стран (`indicators.json`), города с климатом (`cities.json`), границы (`countries.geojson`). Собираются `scripts/build_*.py` и workflow `world-data.yml` раз в месяц.
- `sw.js` — офлайн-кэш своих файлов. После правок кода поднять `VERSION`.

## Проверка

```bash
node --test tests/*.test.mjs
```

Сайт целиком в headless Chrome на моке GitHub и Nominatim: каждый экран на 390 и 1280 px (у всех кнопок есть имя, цель ≥ 24 px, ничего не перекрыто, нет горизонтальной прокрутки) и сценарии — оценка, черновики, вслепую, офлайн-очередь, цифры места, ключ, веса. Нужен установленный Chrome (или путь в `CHROME`).

```bash
node --test tests/e2e/*.test.mjs
```

```bash
python3 -m http.server 8765
```

Живой тест против приватного репо: работает во временной ветке и удаляет её. Токен берётся из окружения.

```bash
WTL_TOKEN="$(gh auth token)" node tests/live-github.mjs
```
