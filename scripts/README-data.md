# Мировые данные: data/world

Два готовых JSON, которые приложение читает статикой. Собираются скриптами отсюда; в браузере ничего не качается.

## indicators.json — показатели по странам

`scripts/build_countries.py`, ~30 с, только стандартная библиотека Python.

- Ключ страны — ISO3 как в Natural Earth: `ISO_A3_EH`, а если там `-99` — `ADM0_A3` (Косово `KOS`, Сев. Кипр `CYN`). World Bank `XKX` и OWID `OWID_KOS` приводятся к `KOS`; агрегаты WB и регионы OWID отброшены.
- Значение — `[число, год]`; у `ru_visa` третий элемент — режим въезда (`visa free`, `visa on arrival`, `eta`, `e-visa`, `visa required`, `no admission`, `home`). У средних за период (`homicide`, `usd_prices`) год — последний.
- Показатели (шкала 1–5, Россия/СПб = 3; что значит каждый — с точки зрения пары на удалёнке с доходом не в местной валюте):
  - `price_level` — World Bank WDI `PA.NUS.PRVT.PLI` (CC BY 4.0), уровень цен потребления, США = 100. Страна в целом, вся корзина вместе с жильём; прыгает вместе с курсом рубля (Россия 31 → 37 за 2024–2025). Колонка «данные» для `цены_услуги`.
  - `usd_prices` — рост цен в долларах, % в год: CAGR отношения `FP.CPI.TOTL` (ИПЦ) к `PA.NUS.FCRF` (местная валюта за доллар) за 5 лет до последнего года, где есть оба ряда. Для того, кто получает в долларах/евро, лирная инфляция Турции не важна, важно, как дорожают цены в валюте дохода. Скачок пересчитанной цены в 3 раза за год — смена валюты или официального курса (Ливан, Ливия), страна пропускается; у Хорватии (евро с 2023) и Болгарии (с 2026) старый курс делится на курс конверсии. Колонка для `динамика_цен`. Шкала `lin`, шаг 2 п.п.
  - `uhc` — WDI `SH_UHC_SCI` (ВОЗ): охват гос. системы базовой помощью, не качество больниц. Колонка для `больница`.
  - `pm25` — WDI `EN.ATM.PM25.MC.M3`, по стране в целом, не по городу. Колонка для `воздух`.
  - `homicide` — WDI `VC.IHR.PSRC.P5` (UNODC): среднее за последний доступный год и 4 года до него, не старше 2005 (`mrnev=5`, лишние годы отбрасываются), год — последний. Один год у малой страны — шум (Черногория 2023: 0,8 против 2,5–3,8 до этого). Бытовую преступность не отражает. Колонка для `преступность`.
  - `wgi_pv` — World Bank WGI, `source=3`, `GOV_WGI_PV.EST` (бывает, отвечает ~50 с): политическая стабильность, шаг 0,5 относительно России. Колонка для `стабильность`.
  - `wgi_cc`, `wgi_ge` — WGI `GOV_WGI_CC.SC` и `GOV_WGI_GE.SC`, 0–100. Группа «Легализация» абсолютная, поэтому шкала тоже абсолютная: 1 + SC/25 (`abs` [[0,1],[100,5]]); Россия ≈ 2,1 и 2,7. Коррупция и госуправление в целом, не миграционная бюрократия для иностранца. Колонки для `бюрократия`.
  - `quake` — INFORM Risk (EC JRC), подындикатор землетрясений `HA.NAT.EQ`, 0–10. Workflow ищется сам: последний `INFORM Risk <год>` в `workflows/GetByWorkflowGroup/INFORM<год>`; API рвёт соединения — в скрипте ретраи. Шкала абсолютная от почти нулевой сейсмики СПб: 0 → 3, 3 → 2,75, 5 → 2,25, 7 → 1,75, 9 → 1,25; лучше СПб не бывает. Значение по стране в целом: у России 4,2, поэтому сам СПб получает 2,45, а не 3. Колонка для `стихии`.
  - `free_speech` — V-Dem freedom of expression index через Our World in Data (`freedom-of-expression-index`, CC BY 4.0), 0–1, последний год. Шаг 0,38: Россия 0,08 → 3, Испания 0,84 → 5. Колонка для `свободы`.
  - `ru_visa` — passport-index-data (MIT, github.com/imorte/passport-index-data, данные с passportindex.org): дни безвиза для паспорта РФ (`visa free` без срока → 90, `visa on arrival` → 30, `eta` → 90, виза и e-visa → 0; Россия = 360, «home»). Снимок на дату из README репозитория, она пишется в `note`. Без `cats`: слой карты и фильтр аэропортов в `build_cities.py`.
- Убраны (октябрь 2026, после сверки с первоисточниками — значения были верны, не подходил смысл):
  - `gdp_ppp`, `hdi`, `happiness` — про доходы и самочувствие местных, не про жизнь приезжих на удалёнке; ВВП ещё и дублировал цены в «похожих местах».
  - `unemployment` — пара работает удалённо; рекордно низкая безработица России как якорь красила всех кандидатов в 1.
  - `internet` — доля пользователей, не скорость.
  - `life_exp` — отражает образ жизни и смертность мужчин в России, а не доступ к больнице; давал Черногории 4,5 за «Серьёзный случай».
  - `inform_risk` — индекс гуманитарных кризисов для планирования помощи.
  - `inform_nat` — у России 5,1 из-за паводков огромной страны, и побережье Черногории (землетрясение 1979 года) выходило безопаснее СПб; заменён на `quake`.
  - `passport_power` — ценность паспорта, а не путь к гражданству; `гражданство` заполнять вручную.
  - `wgi_rl` — без подкатегории, только фон; к «бюрократии» ближе `wgi_cc` и `wgi_ge`.
  - Заменены: `inflation5` (инфляция в местной валюте: Турция 47,8% → 1, хотя в долларах цены там росли медленнее всех) → `usd_prices`; `democracy` (выборы, не цензура) → `free_speech`; `wgi_cc`/`wgi_ge` `.EST` относительно России → `.SC` абсолютно.
- Значения старше 2005 года (`MIN_YEAR`) отбрасываются: у малых территорий World Bank отдаёт замеры 1990-х.
- Шкала 1–5 (`scale`), Россия = 3: `log` — 3 + dir·ln(x/x_RUS)/step, `lin` — 3 + dir·(x − x_RUS)/step, `abs` — кусочно-линейно по порогам; клип делает приложение. В группах «относительно СПб» пороги `abs` подобраны так, чтобы Россия/СПб давали ≈ 3: PM2.5 12 мкг/м³ → 3. Исключения — `quake` (якорь — сам СПб, не Россия) и абсолютные группы (`wgi_cc`, `wgi_ge`, `ru_visa`).
- `cats` — подкатегории методики, для которых показатель служит колонкой «данные». `note` — оговорка для подсказки.

## cities.json — города и климат

`scripts/build_cities.py`, зависимости `rasterio`, `tzdata`. Полный прогон локально — 21 мин (CHELSA 39 файлов × 4719 точек, теперь 40 с `tasmin_07`, 1 км, 16 потоков — 20 мин; упирается в задержку HTTP, не в CPU). `--level 0` читает overview 2 км: вдвое быстрее, разница tas в среднем 0,05 °C, максимум 0,7 °C (kg0 всегда с 1 км).

- Набор (4103 города): GeoNames `cities15000` с населением ≥ 200 тыс.; в странах фокуса (ME RS TR GE AM CY GR HR AL BA MK BG SI ES PT IT KZ AZ) — от 15 тыс., но в ES, IT, TR от 22 тыс.: иначе файл больше 1,5 МБ (выкинуто ES 191, IT 203, TR 90 городов на 15–22 тыс.); Россия от 100 тыс.; Черногория — все `cities1000` (41). Районы и исторические пункты (`PPLX`, `PPLH`, `PPLQ`, `PPLW`) выкинуты. Районы мегаполисов, которые GeoNames держит отдельными городами (Конак, Багджылар, Бруклин), тоже выкинуты: город той же страны минимум вдвое больше ближе 8 км × √(млн жителей), от 6 до 35 км; Черногорию не трогаем. Было 4719, осталось 4103.
- `n` — `rdfs:label@ru` из Wikidata: сначала по GeoNames ID (P1566), батчами по 300; у многих крупных городов P1566 указывает на муниципалитет или ADM2, поэтому второй проход — элемент с тем же `@en`/`@mul` названием и координатами в пределах 25 км. Скобки-уточнения и «район/городской округ» срезаются. Нет — латинское имя GeoNames (~10%, в основном мелкие города Италии и Испании). Единичные промахи возможны (Halle → «Галле (Зале)-Главный»).
- Климат — CHELSA V2.1 climatologies 1981–2010 (CC0), COG по HTTP Range с `os.unil.cloud.switch.ch/chelsa02/chelsa/global/`:
  - `t` — tas по месяцам, °C (в файле K, шкала 0.1); `tx` — tasmax июля (дневной максимум); `tn` — tasmin июля (ночной минимум, ≥ 20 °C — тропические ночи); `tn1` — tasmin января;
  - `p` — pr по месяцам, мм/мес (kg m⁻² month⁻¹, шкала 0.1);
  - `c` — clt по месяцам, % (шкала 0.01; сетка 0.025°, ~3 км);
  - `kg` — kg0 (Köppen-Geiger), коды 1–31 в порядке Kottek: Af Am As Aw BWk BWh BSk BSh Cfa Cfb Cfc Csa Csb Csc Cwa Cwb Cwc Dfa Dfb Dfc Dfd Dsa Dsb Dsc Dsd Dwa Dwb Dwc Dwd EF ET. Легенда проверена пересчётом классов из tas/pr тех же городов: совпадение 93% по классу, 99,7% по главной букве (расходятся пограничные Cfa/Csa и As/Aw).
  - Осадки CHELSA у гор над побережьем завышены (Будва ~2400 мм/год против 1355–1794 по станциям Бар и Херцег-Нови): сравнивать места между собой можно, абсолют — с оговоркой.
  - `tx` у побережья и в городах занижен на 2–4 °C против станций NOAA 1991–2020 (Будва 27,5 против 30–31; Стамбул 26,3 против 28–29,5; СПб 20,7 против 23,3; Анталья совпадает). `tn` против тех же станций: Херцег-Нови 21,1 / 20,0, Будва 23,0 / Бар 20,6, Подгорица 20,5 / 21,6, Стамбул 20,8 / Флорья 20,5, Анталья 24,3 / 23,4, Жабляк 9,6 / 9,2, СПб 13,4 / 15,3: у побережья суточный ход сжат (ночь теплее, день холоднее), СПб холоднее станции.
  - Точка в море (nodata) — ближайший пиксель суши в окне 5×5.
- `el` — высота GeoNames (`elevation`, нет — `dem`); `tz` — смещение от Москвы (UTC+3) в местную зиму (15 января, в южном полушарии 15 июля), ч; `air` — км по прямой до ближайшего аэропорта OurAirports (public domain) типа `large_airport` или `medium_airport` с `scheduled_service = yes` (закрытый Ататюрк выпал, Тиват попал). Аэропорты стран, куда паспорту РФ нужна виза (`ru_visa` = 0 в `indicators.json`), не считаются, кроме своей страны и своей Шенгенской зоны: Херцег-Нови → Тиват, а не Дубровник, у испанских городов испанские аэропорты остаются. По прямой: Альхесирас → Танжер через пролив 61 км, Жабляк 89 км, по дороге заметно дальше; `cc` — ISO3 по Natural Earth `ISO_A2_EH`.
- Размер: 1,31 МБ, gzip 0,44 МБ.

## Как перезапустить

Локально:

```
uv run python scripts/build_countries.py
uv run --with rasterio --with tzdata python scripts/build_cities.py --workers 16
```

Пересчитать только часть полей готового `cities.json` (города, имена и остальной климат не трогаются): `--update air` — аэропорты, ~25 с, без rasterio; `--update tn,tn1` — два растра CHELSA, ~2 мин: один растр делится на потоки по регионам. Аэропортам нужен свежий `indicators.json` (фильтр по `ru_visa`), поэтому страны собираются первыми.

```
python3 scripts/build_cities.py --update air
uv run --with rasterio --with tzdata python scripts/build_cities.py --update tn,tn1 --workers 16
```

Кэш скачанного — во временной папке (`--cache`). Сэмплы CHELSA кэшируются по растру и по точке: прерванный прогон продолжается с места, а после правки списка городов досэмплируются только новые точки.

В GitHub: Actions → world-data → Run workflow (галка `cities` — пересобрать и города). По расписанию 5-го числа в 03:00 UTC обновляются только страны; коммит — только если данные изменились.
